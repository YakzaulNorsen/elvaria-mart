# Elvaria Mart Collection

Premium static storefront for bags, ladies watches and jewellery. Built with plain HTML, CSS and JavaScript so it can be hosted directly on GitHub Pages.

## Quick edits

- Replace `assets/cover.jpg` with your preferred cover image.
- Replace `assets/logo.jpg` with your preferred logo.
- Open `script.js` and change `whatsappNumber` to your real WhatsApp number.
- Edit sample product names and PKR prices in `index.html`.
- Replace the Facebook/contact links with your real business links.

## GitHub Pages

Upload the contents of this folder to a GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.

For a project repository, the site will normally be available at:
`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

For a user site, create a repository named:
`YOUR-USERNAME.github.io`
